THE STANDARD — predict first, observe second, score third.OPEN METHODS · AUDITABLE RECORDS
01

Before the move.

Models receive the same recorded chess position. Their predictions are published ahead of the human decision.

02

Against the human.

Exact-match accuracy measures whether a model anticipates the player’s actual choice, not just a strong move.

03

Open to inspection.

Every observation links back to a game position, model specification, prediction record, and outcome source.

02 /

Predictions without hindsight.

Publishing a result is straightforward. Establishing that a prediction existed before the human move is the actual challenge.

01 / INPUT

The board position, legal moves, model version, and prompt specification are recorded.

02 / PUBLICATION

A public Git commit ahead of the next move provides an externally inspectable publication record. A local timestamp alone does not establish priority.

03 / SCORING

Observed moves are sourced from a public broadcast. Exact matches are counted separately from Stockfish assessment, which is not yet integrated.

04 / LIMITS

Git history does not independently attest model-provider identity or response origin. Those claims need provider evidence and additional controls.
